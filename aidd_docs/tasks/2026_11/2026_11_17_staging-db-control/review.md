| 🔴 | functional | 1 | `code/api/internal/routes/staging.go:19,44` | Route path mismatch: `Staging()` registers `/status` and `/start`, mounted at `/infra` in `app.go:61`, so the real paths are `/v1/infra/status` and `/v1/infra/start`. This defeats the feature's primary flow: start stg from the back-office, then use it. | Add a start grace period: refuse to stop unless the instance has been `available` for at least 30 minutes — e.g. require the metric window to be fully covered by datapoints, or stamp a start timestamp (RDS tag) on `StartDBInstance` and honour it in the handler. |
