# Backlog

## Supports

| Support | Authority for | Role |
| --- | --- | --- |
| `GitHub Issues` | user stories, bugs | tracker |

## Representation

| Artifact | Support | Native representation |
| --- | --- | --- |
| User Story | GitHub Issues | `.github/USER_STORY_TEMPLATE.md` (As a/I want/So that, acceptance criteria, Definition of Done) |
| Bug | GitHub Issues | `.github/BUG_TEMPLATE.md` (repro steps, severity) |

## Relations

- Dependency: cross-reference by issue number in the story's "Dependencies" field (e.g. `Blocked by #45`)
